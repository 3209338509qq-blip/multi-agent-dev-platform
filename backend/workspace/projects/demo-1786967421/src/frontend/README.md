# 大学生班费管理系统 - 前端说明

## 项目描述
这是一个大学生班费管理系统的前端界面，用于管理班费的收入和支出，并查看交易记录。

## 技术栈
- 单文件HTML，包含嵌入式CSS和JavaScript
- 使用原生fetch API与后端通信
- 响应式设计，支持手机和电脑

## API端点假设
前端假设以下API端点（需要后端实现）：
- `GET /api/balance` - 获取当前班费余额
- `POST /api/income` - 添加收入记录，请求体：`{ amount, description }`
- `POST /api/expense` - 添加支出记录，请求体：`{ amount, description }`
- `GET /api/transactions` - 获取所有交易记录

## 功能
1. 显示当前班费余额
2. 添加收入或支出记录
3. 查看所有交易记录
4. 错误处理和提示

## 如何运行
1. 确保后端API可用并运行在相同域或通过代理。
2. 直接打开 `index.html` 文件在浏览器中。
3. 如果遇到跨域问题，需要配置后端允许CORS或使用本地服务器。

## 注意事项
- 所有API调用都有错误处理，界面会显示错误信息。
- 设计为离线可运行，但需要后端API支持。
- 响应式布局，适配不同屏幕尺寸。
