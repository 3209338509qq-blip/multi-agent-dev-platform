# 大学生班费管理系统 - 前端

这是一个简单的大学生班费管理系统前端实现，采用单文件HTML设计，包含嵌入式CSS和JavaScript。

## 功能特性

- **查看班费记录**：以卡片形式展示所有班费记录，包括日期、描述、金额和操作人
- **添加新记录**：通过表单添加新的班费记录，支持表单验证
- **删除记录**：确认后删除指定的班费记录
- **响应式设计**：适配桌面和移动设备，提供良好的用户体验
- **错误处理**：所有API调用都包含错误处理和用户反馈
- **离线运行**：无外部CDN依赖，可直接在本地打开使用

## 技术实现

- **前端技术**：原生HTML5, CSS3, JavaScript (ES6+)
- **API交互**：使用Fetch API进行HTTP请求
- **响应式布局**：使用CSS媒体查询和弹性盒布局
- **状态管理**：DOM直接操作，实时更新界面

## 使用说明

### 前提条件

1. 确保后端API服务已启动并运行
2. 后端API应提供以下端点：
   - `GET /api/fees` - 获取所有班费记录
   - `POST /api/fees` - 添加新记录（JSON格式：{date, description, amount, operator}）
   - `DELETE /api/fees/:id` - 删除指定ID的记录

### 运行步骤

1. 直接打开 `index.html` 文件即可使用
2. 系统会自动加载班费记录列表
3. 使用表单添加新的班费记录
4. 点击记录中的删除按钮可删除记录

## 注意事项

1. **API端点配置**：当前代码假设后端API在 `/api/fees` 路径下。如实际API路径不同，需要修改JavaScript中的fetch请求URL。

2. **数据格式**：前端发送和接收的JSON数据格式需要与后端API保持一致。

3. **编辑功能**：当前版本的编辑功能仅作为演示，显示提示信息。如需完整编辑功能，需要扩展实现。

4. **错误处理**：系统包含基本的错误处理，但生产环境中可能需要更完善的错误处理机制。

5. **安全性**：此为前端演示项目，实际应用中需要考虑用户认证、数据验证和XSS防护等安全措施。

## 自定义配置

如需修改API端点或其他配置，请编辑 `index.html` 文件中的JavaScript代码，找到相应的fetch请求进行修改。
